# gendaibun-print — 現代文授業プリント作成用テンプレート

益田先生の現代文プリント（A4 横・縦書き）の組版を固定したまま、教材だけを差し替えて
授業プリントを作るための道具一式。1 学期の『ぬくみ』授業プリント①〜④を原本にしている。

古文プリント（[kobun-print](https://github.com/sakadosoutan-boop/kobun-print)）で
試行錯誤して確かめたやり方をそのまま受け継いでいる。

- **テンプレートは原本 docx の組版をそのまま使う**。作り直していないので、MEMO 帯・
  「授業の前に」の囲み・段落表のラベル・枠・【ねらい】の電球アイコンの位置は原本と同じ
- **教材データ（JSON）**に各ページの文言を書くと、テンプレートに流し込んで docx ができる
- **解答の見せ方を一括で切り替えられる**（赤字の解答版／空欄の配布用／黒の解答例）
- **分量チェック**で、原本の紙面に収まるかを描画せずに見積もる
- **表記チェック**で、前の教材の文言の残り・参照ページの範囲外・括弧の不一致などを拾う

書いた。4 ページの構成は次のとおり。

| ページ | 段 | 小見出し | 主な内容 |

## すぐ使う

```bash
python3 src/build.py data/病と科学.json -o build/病と科学.docx                    # 解答版
python3 src/build.py data/病と科学.json -o build/病と科学_配布用.docx --answers 空欄  # 配布用
python3 tools/check.py data/病と科学.json                                          # 表記チェック
python3 tests/verify.py                                                            # 検証一式
```

### 次の教材を作る

```bash
cp data/_雛形_授業プリント.json data/○○.json     # 雛形を写して中身を書く（data/病と科学.json が実例）
python3 tools/check.py data/○○.json
python3 src/build.py data/○○.json -o build/○○.docx
```

## 区画

1 枚目（①②）・2 枚目（③④）の各ページを区画に分けてある。行数は原本の行数。

| 区画 | ① | ② | ③ | ④ | 中身 |
|---|---|---|---|---|---|
| ヘッダ | 1 | 1 | 1 | 1 | 【二年 論理国語】『題名』授業プリント①　氏名欄　表／裏 |
| 授業の前に | 1 | | | | 授業前の問い（「＊授業の前に」「下書き」の見出しは原本の文字のまま） |
| キーワード | 1 | | | | 音読のときに注意するキーワード |
| 段落表 | 4 | | | | 第一段〜第四段の範囲と小見出し（『 』の中が答え） |
| 段見出し | 1 | 1 | 1 | 1 | その段の範囲 |
| ねらい | 1 | 1 | 1 | 1 | 【 その段のねらい 】（電球アイコンの後ろ） |
| 学習 | 20 | 37 | 20 | 12 | 主題・例・主張・意味・理由・まとめの主張 |
| 脚問 | 2 | 2 | 4 | 2 | 脚問（発問）と答の組 |
| 設問 | | | | 13 | 設問の見出しと 問一〜問六 |

- **行が原本より少ない区画**は、残りを空行にして場所を取っておく（後ろの脚問や枠が寄ってこない）
- **行が原本より多い区画**は行を増やせる。ただし分量チェックで ⚠ が出たら紙面からはみ出すおそれがある
- **学習・設問**は、各ページの見本の段落（レシピの「見本の段落」）の書式にそろえて組み直す。
  字下げは行頭の全角スペースで書く
- ヘッダ・ねらい・① の脚問は図形やアイコンと組になっているので行数を変えられない

### 記法

| 記法 | 意味 | 例 |
|---|---|---|
| `{語}` | 答え（赤字）。配布用では白字になり空欄に見える | `（　{科学信仰}　）` |
| `{{語}}` | 隠し答え（白字） | |
| `_語_` | 傍線 | |
| `<<囲み\|語>>` | 囲み（意味・理由・脚問・発問 などの見出し） | `<<囲み\|意味>>` |
| `<<太字\|語>>` | 太字（【例１】【主張１】 など） | `<<太字\|【例１】>>` |
| `<<囲み太字\|語>>` | 囲み＋太字（主張①・答・第一段・問一） | `<<囲み太字\|主張①>>` |
| `<<大\|語>>` / `<<小\|語>>` | 11pt / 9pt | `<<大\|【 >>` |
| `<<書式NN\|語>>` | 原本に残る細かな書式（`template/授業プリント/spans.json`） | |
| `\[` など | 記号そのもの | |

本文の参照は `（109・8）`（ページ・行）、段の範囲は `Ｐ１０８・Ｌ１` と全角で書く（原本どおり）。
`meta.ページ範囲` を書いておくと、表記チェックが範囲外の参照を拾う。

## 組んだときに出る報告

```
→ build/病と科学.docx（解答: 原本どおり）
  空行で埋めた区画: ②・学習 29/37 行（残りは空行）
  分量（①）: 原本 36 行分 → 今回 36 行分（99%）
  分量（②）: 原本 45 行分 → 今回 43 行分（96%）
```

**分量**は、段の長さと文字の大きさから縦書き 1 行に入る字数（10pt で 52 字）を出し、
教材が何行分になるかを原本と比べたもの。100% 以下なら紙面からはみ出すことはまずない。

`--answers` の指定:

| 指定 | 何が起きるか |
|---|---|
| `原本どおり` | 赤字は赤字、白字は白字のまま（既定） |
| `答え` | 白字の隠し答えも赤字にして、すべて見せる |
| `空欄` | 赤字の答えを白字にして、すべて空欄にする（配布用） |
| `黒` | すべての答えを黒字にする（モノクロ印刷の解答例） |

## 確かめる

```bash
python3 tests/verify.py
NUKUMI_DOCX=原本.docx python3 tests/verify.py   # 原本があれば、作り直しと 1 ドット比較も
```

1. 原本からレシピでテンプレートを作り直すと、リポジトリのものと同じになること。
   「テンプレート＋原本の文言」が「原本にレシピを当てただけのもの」と 1 ドットも変わらないこと
2. 『病と科学』が組めて、目印の取り残しや空の区画が無く、分量が原本以下であること
3. `--answers` の各指定で、消えるべき色の文字が 0 字になること
4. 表記チェックに ✗ が無いこと
5. LibreOffice で 4 ページに収まること（目安）

画像の比較には LibreOffice と poppler-utils が要る（無ければ省略）。Python 3.10 以上、標準ライブラリのみ。

LibreOffice は UD デジタル教科書体を持たないので、プレビューは字形も行送りも Word と違う
（原本そのものでも ③④ の行が詰まって見える）。紙面に収まるかは分量で見て、最終確認は Word で。

## テンプレートを作り直す

原本 docx は図版（アニメの場面写真など）を含むのでリポジトリには入れていない。
手元の原本からいつでも同じテンプレートを作り直せる。

```bash
python3 tools/make_template.py 原本.docx --name 授業プリント
```

原本に何をするかは `template/授業プリント/recipe.json` に書いてある（取り除く図形、
錨を移す図形、図形の位置の固定、改ページ、区画の段落番号）。詳しい理由は
[docs/設計メモ.md](docs/設計メモ.md)。
