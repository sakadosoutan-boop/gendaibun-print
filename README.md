# gendaibun-print — 現代文授業プリント作成用テンプレート

益田先生の現代文プリント（A4 横・縦書き）の組版を固定したまま、教材だけを差し替えて
授業プリントを作るための道具一式。1 学期の『ぬくみ』授業プリント①〜④を原本にしている。

古文プリント（[kobun-print](https://github.com/sakadosoutan-boop/kobun-print)）で
試行錯誤して確かめたやり方をそのまま受け継いでいる。

- **テンプレートは原本 docx の組版をそのまま使う**。作り直していないので、MEMO 帯・
  「授業の前に」の囲み・段落表のラベル・枠・【ねらい】の電球アイコンの位置は原本と同じ
- **教材データ（JSON）**に各ページの文言を書くと、テンプレートに流し込んで docx ができる
- **解答の見せ方を一括で切り替えられる**（赤字の解答版／空欄の配布用／黒の解答例）
- **図解・挿絵**を、各ページの内容に合わせて差し込める（答えの字は解答版で赤、配布用で空欄）
- **横幅の見積もり**で、各ページが紙面に収まるかを描画せずに確かめる
- **表記チェック**で、前の教材の文言の残り・参照ページの範囲外・括弧の不一致などを拾う

## できているもの

| ファイル | 中身 |
|---|---|
| `prints/病と科学_授業プリント_解答.docx` | 『病と科学』授業プリント①〜④（答えは赤字） |
| `prints/病と科学_授業プリント_配布用.docx` | 同じものの答えを白字にした配布用（空欄に見える） |
| `prints/雛形_授業プリント.docx` | 区画の名前だけが入った雛形（Word で直接打ち込む用） |
| `data/病と科学.json` | 『病と科学』の教材データ（上の 2 つの元） |
| `docs/ワーク案_病と科学.md` | 体感ワーク案（思考実験・スキット・逸話）。①〜④の段と設問に対応させた教員向けの手引き |

『病と科学』は指導書（要旨・全体の構成・展開図・語句の解説・脚問・発問・課題）をもとに
書いた。4 ページの構成は次のとおり。

| ページ | 段 | 小見出し | 主な内容 |
|---|---|---|---|
| ①（表） | 授業の前に・段落表・第一段（p.108 L1〜p.109 L16） | 科学崇拝への道 | 病原菌の発見→科学信仰→医師への依存。発問「信仰にも似ている」 |
| ②（裏） | 第二段（p.110 L1〜p.111 L5） | 科学の限界を忘れる | 数値化・病人と病気の切り離し→万能の錯覚。脚問「数値の魔術」 |
| ③（表） | 第三段（p.111 L6〜p.113 L3） | 自己感覚の否定 | 痛みの否定→依存→受容する能力の喪失。発問 2 問 |
| ④（裏） | 第四段（p.113 L5〜終わり）・設問 | 科学の功罪 | 利益と弊害→筆者の主張。脚問「『病人』が出現する」。設問 問一〜問六 |

各ページに図解（挿絵入り）を 1 枚ずつ入れてある。

| ページ | 図 | 中身 | 大きさ |
|---|---|---|---|
| ① | 科学崇拝への道 | 雷雲（神の怒り）→顕微鏡と病原菌（病原菌の発見）→科学信仰→医師（強い自信）→病人（医師への依存）の流れ | 23×130mm |
| ② | 病人と病気の切り離し | 「病人」の円と「病気」の円をはさみの点線で切り離し、測定・検査できる症状だけが数値（検査画面）になり、答えられない部分が切り捨てられる | 41×145mm |
| ③ | 痛みの否定と依存 | 「痛い！」と訴える患者と、データ画面で「異常なし」と判断する医師→感覚の否定→「先生に任せよう」（依存）→苦しみを受容する能力を失う | 55×145mm |
| ④ | 科学の功罪 | 天秤の功（利益）と罪（弊害）、遺伝子（二重らせん）と経済的利益の危険→筆者の主張（双葉＝自然と向き合う） | 47×145mm |

図の中の答えの字（神・科学信仰・依存・数値・人間・否定・受容・無能力・正常値・利益・限界・自然）は、
本文の空欄と同じく解答版で赤字、配布用で空欄（〔　〕だけ残る）になる。

## すぐ使う

```bash
python3 src/build.py data/病と科学.json -o build/病と科学.docx                    # 解答版
python3 src/build.py data/病と科学.json -o build/病と科学_配布用.docx --answers 空欄  # 配布用
python3 tools/check.py data/病と科学.json                                          # 表記チェック
python3 tests/verify.py                                                            # 検証一式
```

### 次の教材を作る

```bash
cp data/_雛形_授業プリント.json data/○○.json     # 雛形を写して中身を書く（data/病と科学.json が実例）
python3 tools/check.py data/○○.json
python3 src/build.py data/○○.json -o build/○○.docx
```

## 区画

1 枚目（①②）・2 枚目（③④）の各ページを区画に分けてある。行数は原本の行数。

| 区画 | ① | ② | ③ | ④ | 中身 |
|---|---|---|---|---|---|
| ヘッダ | 1 | 1 | 1 | 1 | 【二年 論理国語】『題名』授業プリント①　氏名欄　表／裏 |
| 授業の前に | 1 | | | | 授業前の問い（「＊授業の前に」「下書き」の見出しは原本の文字のまま） |
| キーワード | 1 | | | | 音読のときに注意するキーワード |
| 段落表 | 4 | | | | 第一段〜第四段の範囲と小見出し（『 』の中が答え） |
| 段見出し | 1 | 1 | 1 | 1 | その段の範囲 |
| ねらい | 1 | 1 | 1 | 1 | 【 その段のねらい 】（電球アイコンの後ろ） |
| 学習 | 20 | 37 | 20 | 12 | 主題・例・主張・意味・理由・まとめの主張 |
| 脚問 | 2 | 2 | 4 | 2 | 脚問（発問）と答の組 |
| 設問 | | | | 13 | 設問の見出しと 問一〜問六 |

- **行が原本より少ない区画**のうち、段落表・脚問など書式の決まった区画は、残りを空行にして場所を取っておく
- **行は増やせる**。ただし横幅の見積もりで ⚠ が出たら次のページへあふれるおそれがある
- **学習・設問**は、各ページの見本の段落（レシピの「見本の段落」）の書式にそろえて組み直す。
  字下げは行頭の全角スペースで書く
- ヘッダ・ねらい・① の脚問は図形やアイコンと組になっているので行数を変えられない

### 記法

| 記法 | 意味 | 例 |
|---|---|---|
| `{語}` | 答え（赤字）。配布用では白字になり空欄に見える | `（　{科学信仰}　）` |
| `{{語}}` | 隠し答え（白字） | |
| `_語_` | 傍線 | |
| `<<囲み\|語>>` | 囲み（意味・理由・脚問・発問 などの見出し） | `<<囲み\|意味>>` |
| `<<太字\|語>>` | 太字（【例１】【主張１】 など） | `<<太字\|【例１】>>` |
| `<<囲み太字\|語>>` | 囲み＋太字（主張①・答・第一段・問一） | `<<囲み太字\|主張①>>` |
| `<<大\|語>>` / `<<小\|語>>` | 11pt / 9pt | `<<大\|【 >>` |
| `<<書式NN\|語>>` | 原本に残る細かな書式（`template/授業プリント/spans.json`） | |
| `\[` など | 記号そのもの | |

### 図解・挿絵

学習・設問の区画の行の並びの中に、文字列の代わりに次のように書くと、その場所に図が入る。

```json
{"図": "figures/病と科学/図2_病人と病気の切り離し.svg", "行": 7, "幅": 41, "高さ": 145, "説明": "図解：…"}
```

- 「行」の数だけ空行を取り、その帯の中央に図を置く（横は行に付いて動くので、前の行数が変わってもずれない）
- 「幅」は、空けた行の幅（①② は 1 行 6.2mm 以上、③④ は 4.1mm 以上）に収める。「上」（mm）で縦の位置も指定できる（既定は中央）
- 文字の折り返しは「四角」。見積もりがずれても、文字は図をよけて流れる
- 図は `figures/<教材>/make_figures.py` で描く（`tools/zukai.py` の部品: 人・医師・顕微鏡・病原菌・雷雲・検査画面・天秤・遺伝子・双葉・はさみ・吹き出し、箱・矢印・答えの欄）。
  1 枚から、答えが赤字・`_空欄`・`_黒` の 3 版の SVG と PNG ができ、build が `--answers` に合わせて選ぶ

```bash
python3 figures/病と科学/make_figures.py      # 図を描き直す（PNG には LibreOffice が要る）
```

Word に入れるのは PNG（約 400dpi）。SVG は図を直すときの元。

本文の参照は `（109・8）`（ページ・行）、段の範囲は `Ｐ１０８・Ｌ１` と全角で書く（原本どおり）。
`meta.ページ範囲` を書いておくと、表記チェックが範囲外の参照を拾う。

## 組んだときに出る報告

```
→ build/病と科学.docx（解答: 原本どおり）
  行数を変えた区画: ③・学習 20→32 行
  図: ③・学習: 図3_痛みの否定と依存（14 行）
  分量（③）: 原本 30 行分 → 今回 40 行分（133%）
  横幅（①）: 261mm／272mm
  横幅（③）: 222mm／272mm
```

**横幅**は、各ページに並ぶ行の幅（字の大きさ×1.39＋段落前の間隔）を足し上げたもの。
本文領域 272mm から余裕 6mm を引いた 266mm を超えると ⚠ が出る。行の幅の 1.39em は
『ぬくみ』原本から逆算した値（docs/設計メモ.md）。
**分量**は原本の行数との比べ（参考）。原本は ③④ の左半分を空けていたので、図を入れると 100% を超えるが問題ない。

`--answers` の指定:

| 指定 | 何が起きるか |
|---|---|
| `原本どおり` | 赤字は赤字、白字は白字のまま（既定） |
| `答え` | 白字の隠し答えも赤字にして、すべて見せる |
| `空欄` | 赤字の答えを白字にして、すべて空欄にする（配布用） |
| `黒` | すべての答えを黒字にする（モノクロ印刷の解答例） |

## 確かめる

```bash
python3 tests/verify.py
NUKUMI_DOCX=原本.docx python3 tests/verify.py   # 原本があれば、作り直しと 1 ドット比較も
```

1. 原本からレシピでテンプレートを作り直すと、リポジトリのものと同じになること。
   「テンプレート＋原本の文言」が「原本にレシピを当てただけのもの」と 1 ドットも変わらないこと
2. 『病と科学』が組めて、目印の取り残しや空の区画が無く、各ページの横幅が本文領域に収まること。図が 4 枚入ること
3. `--answers` の各指定で、消えるべき色の文字が 0 字になり、図もその版（赤字／空欄／黒）が入ること
4. 表記チェックに ✗ が無いこと
5. LibreOffice で 4 ページに収まること（目安）

画像の比較には LibreOffice と poppler-utils が要る（無ければ省略）。Python 3.10 以上、標準ライブラリのみ。

LibreOffice は UD デジタル教科書体を持たないので、プレビューは字形も行送りも Word と違う
（原本そのものでも ③④ の行が詰まって見える）。行が詰まるぶん、LibreOffice では図が後ろの行に
かぶって、その行が図の下へ回り込む。紙面に収まるかは横幅で見て、最終確認は Word で。

## テンプレートを作り直す

原本 docx は図版（アニメの場面写真など）を含むのでリポジトリには入れていない。
手元の原本からいつでも同じテンプレートを作り直せる。

```bash
python3 tools/make_template.py 原本.docx --name 授業プリント
```

原本に何をするかは `template/授業プリント/recipe.json` に書いてある（取り除く図形、
図の見本、錨を移す図形、図形の位置の固定、改ページ、区画の段落番号）。詳しい理由は
[docs/設計メモ.md](docs/設計メモ.md)。
