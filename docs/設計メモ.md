# 設計メモ — 『ぬくみ』から『病と科学』へ

## 1. 古文プリント（kobun-print）から受け継いだこと

古文プリントで試行錯誤して確かめたことを、そのまま現代文に持ち込んだ。

| 知見 | 古文プリントで起きたこと | このリポジトリでの扱い |
|---|---|---|
| 組版は原本の XML をそのまま使う | 作り直すと枠や巻物の位置が必ずずれた | 原本にレシピの加工だけを当て、文字の入る場所を目印 ⟦s0001⟧ に置き換える |
| 原本の再現を 1 ドットで確かめる | 書式の取りこぼしは目視では見つからない | 「テンプレート＋原本の文言」と「原本（レシピ適用）」を LibreOffice で描いて画素ごとに比較 |
| 図形入り run の判定は局所名で | `mc:AlternateContent` を w: で探して ☆３ の枠を消していた | `slots.local()` で判定 |
| 行数が減ったら空行で場所を取る | 行を減らすと枠が寄り集まって崩れた | 少ない区画は空行で埋める（報告に「空行で埋めた区画」と出る） |
| 解答は色で切り替える | 赤字・白字（隠し答え）が混在していた | `--answers 原本どおり／答え／空欄／黒` |
| ページ数ではなく分量で見る | LibreOffice のページ数は当てにならなかった | 縦書き 1 行の字数から原本比の行数を出す |
| 前の教材の文言が残る | あだし野の露に、前の教材の設問が残っていた | `tools/check.py` が原本の行・題名の残りを ✗ にする |
| 括弧の全角・半角の混在 | 現代語訳の解答の括弧が混ざっていた | `tools/check.py` が数の不一致・半角を拾う |

## 2. 今回わかったこと（現代文の原本ならでは）

### 区画は文字の形ではなく段落番号で決める
古文プリントは「本文は教科書体」「現代語訳は罫線の枠」など書式で区画を推定できたが、
『ぬくみ』はどの段落も同じ書体・同じ大きさで、見出しと本文が見分けられない。
そこで `recipe.json` に区画を段落番号の範囲で書き、空行も含めて 1 段落 1 スロットにした。

### 縦書きの図形の横位置は「錨の行」から測られる
原本の MEMO 帯（幅 270mm の横長の帯、ページ下の余白にある）は、4 ページとも横位置が
「段組基準」で、値は -27.7mm・-254.9mm・-99.7mm・-68.6mm とばらばらだった。
錨の段落の行の位置から測ると、どれもページの左端になる。縦書きでは段組基準の横位置は
錨の段落の行からの距離になるということ。

本文の区画の段落に錨があると行数を増減できないので、MEMO 帯の錨をヘッダの段落に移し、
位置を「余白基準の中央・ページ基準の高さ」に置き直した（レシピの「錨を移す」「位置を固定」）。
LibreOffice でも、錨を移しただけだと ③ の MEMO の見え方が変わることを確かめている。

### ページの頭は改ページでそろえる
原本は ③ と ④ の間に空行を 17 行入れてページの頭をそろえていた。① と ② の間は改ページが無く、
① があふれた分がそのまま ② に流れる作りだった。行数が変わると崩れるので、
②③④ のヘッダの段落に「段落前で改ページ」を付け、空行は取り除いた。

### 取り除いたもの
| 何を | なぜ |
|---|---|
| 挿絵・人物アイコン・図解の矢印や吹き出しなど 39 個の図形 | 『ぬくみ』の内容に結び付いている。挿絵はアニメの場面写真で、配布物に残せない |
| ① の QR コード | 『ぬくみ』用のリンクと思われる。必要なら『病と科学』用を貼り直す |
| ② の 2 段組（前近代／近代の対比） | 教材によって図解が変わるので 1 段組にそろえた |
| 埋め込みフォント（UD デジタル教科書体のサブセットなど） | フォントのデータをリポジトリで配らないため。Windows 10 以降には同じ書体が入っている。サブセットには『ぬくみ』で使った字しか無いので、残しても新しい教材の字は出ない |

残したもの: MEMO 帯（4 ページ）、「授業の前に」の角丸の囲み、「段落・小見出し」のラベル、
① と ② の大枠、① の答の括弧、【ねらい】の電球アイコン。

## 3. 『病と科学』の教材データについて

- 出どころは指導書（要旨・全体の構成・展開図・語句と文脈の解説・脚問・発問・課題の解答例）。
  本文の引用は、指導書に行番号つきで引かれている語句だけを使った。
- 段の範囲は指導書の「全体の構成」に従った。**第三段の始まりは指導書では 111・6**
  （「科学は人間…」）。1 学期に作った構造図（『病と科学』の空欄補充の図）は p.111 l.7 に
  なっているので、どちらが正しいか教科書で確かめてほしい。
- 教科書の脚問は 2 つ（110・6「数値の魔術」、113・14「『病人』が出現する」）なので、
  ② と ④ は脚問、① と ③ は指導書の発問を「発問」の見出しで入れた。
- 空欄の答えは、1 学期に作った構造図の空欄（神・科学・医師・依存・数値・人間・測定・限界・
  自然 など）とおおむねそろえた。
- 設問 問一〜問六 は課題Ａ一〜四と語句の解説から作った。原本どおり問いだけで、解答は入れていない。

## 4. 原本（『ぬくみ』）で見つかった点

`tools/check.py` と目視で見つけたもの。原本は直していない（テンプレートの元の文言として
`defaults.json` に残っている）。

| 場所 | 内容 |
|---|---|
| ①・学習 | 「（　最も苦しい )」の括弧が全角で開いて半角で閉じている。「( 　無関心 　)」「(　意識の宛先　)」も半角 |
| ①・学習 | 「「キレる」という言葉は。感情の発露が…」の「は。」 |
| ③④・学習 | 空欄の答え（行動・教育課程・条件 など）が赤字になっていない（①② は赤字） |
| ③・脚問 | 「『不要』の烙印を押される」（44）に行番号が無い |
| 段見出し | ① は〈 〉、② は半角の < >、③④ は全角の ＜ ＞ と、範囲の括弧がページごとに違う |
| ② | 「個人関係」と「個人的関係」、「宛先」と「宛て先」が混在 |
| ② | 段見出しの後ろに「参考：教科書　Ｐ４００」が残っている |
