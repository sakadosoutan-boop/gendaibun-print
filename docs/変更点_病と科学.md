# 『病と科学』原案 → 完成版の変更点

先生が原案（`prints/病と科学_授業プリント_解答.docx` ＋ `_体感ワークシート`）をもとに仕上げた完成版
（2026 年 10 月 22 日版）と突き合わせた結果。次の教材の原案は、この表の「次からの原案」に合わせて作る。

## 1. 構成

| 変更点 | 原案 | 完成版 | 次からの原案 |
|---|---|---|---|
| ワークシートの扱い | 授業プリント①〜④と体感ワークシート①〜④の 2 冊 | **ワークを授業プリントの中に入れた**（①の頭に科学信仰度チェック、②の左の枠に健康診断票、③の左の枠にスキット）。ワーク 1・4・5 は使わなかった | ワークは別紙にせず、各ページの左側に「ワーク」の枠で入れる。1 ページ 1 つまで |
| ①の頭 | 「授業の前に」（病気の捉え方など 3 問）＋下書き | 「授業の前に」を外し、科学信仰度チェック（6 問・前後の欄・信仰度計）に置き換えた | ①の頭は、その教材の導入ワーク（自己診断のチェックなど）にする |
| 設問 | ④に問一〜問七 | **問一〜七をやめた**。④に「筆者は…どう向き合うべきか」を、指導書の課題Ａの解答例を穴埋めにした要約（［科学信仰］［科学万能の錯覚］［科学技術の使い方］［科学との向き合い方］の見出しつき）と、課題Ｂの調べ学習欄（調べたワード／現状／倫理的問題） | ④は「筆者の主張のまとめ（課題Ａの解答例の穴埋め・見出しつき）」と「課題Ｂの欄」にする |
| 段落表の数字 | 一部を赤字（答え）に | すべて黒（範囲は与える）。小見出しだけ赤字 | 範囲は黒、小見出しだけ答え |

## 2. 読解の細かさ

| 変更点 | 完成版の例 | 次からの原案 |
|---|---|---|
| 本文の論理の流れを一段細かく | 第一段に「大きな希望 → 幻想 → それでも希望が残る → 信仰に似ている」の流れを加え、まとめの一文「かつて、神のみに与えられていた能力を、人々は、科学に求め、信じた。」（太字）を入れた | 段の中の論理の転換（逆接・言い換え・結論）を一行ずつたどる |
| 言い換えの連鎖 | 「★ 言い換え」の印で、同じ内容の言い換えを並べた（例：（すべての病気に科学の力で克つ）＝（全ての病気は科学の力で理解）＝「科学は全知である」） | 言い換えには ★ と小さく「言い換え」を付ける |
| 囲みの見出しを増やした | 前近代／近代以降、大きな希望、幻想、理由、意味、言い換え | 例・主張のほかに、内容に合わせた囲み見出しを使う |
| ㊟ の補足 | ㊟ 例）薬、安静期間、入退院、手術／㊟ 視力検査の数値によって目の良し悪しを図る／㊟ 合理主義 | 具体例や背景知識は ㊟ で一言添える |
| 本文の行番号 | 「医学が病人と病気を切り離し、人間を無視」（P110・L15） | 引用には（P・L）を付ける |
| 空欄の答え | 指導書の解答例・解説の言葉をそのまま空欄に（科学の本質、自己決定論、社会現象としての恐れ、健康感 など） | 空欄の答えは指導書の言葉に合わせる |
| 脚問の答 | 指導書の答えを全文（「数値の魔術」は後半の「また、数値化されない事柄に…」まで） | 脚問・発問の答は指導書の全文 |
| 主張の見出し | 「主張①（導入）」のように段の役割を添えた | 段の主張には役割（導入・展開・結論など）を添える |

## 3. 図・挿絵

| 原案の図 | 完成版 | 次からの原案 |
|---|---|---|
